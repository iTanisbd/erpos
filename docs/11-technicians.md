# Purpose

Technicians perform repair and service operations.

---

# Fields

- Code
- Name
- Phone
- Email
- Skill Level
- Daily Capacity
- Status

---

# Business Rules

- Technician code must be unique.
- One repair ticket can be assigned to one technician.
- Technician can handle multiple repair tickets.
